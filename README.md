# 💻 Dell Retail Media Showcase (RMN Website V1)

A high-performance, responsive single-page web application inspired by the **Dell Retail Media Network (RMN Website V1)** storyboard. Built with **React 19, TypeScript, Vite, and Tailwind CSS**, this project showcases Dell's flagship laptop lineup, AI features, sustainability initiatives, and promotional accessory bundles.

---

## 🌟 Key Features

- **🚀 Cinematic Landing Page**: Smooth section-by-section scrolling with interactive tabs, glassmorphism UI, and dark blue/cyan Dell theme branding.
- **💻 Dell Inspiron 14 Plus 2-in-1 Showcase**: Highlights Copilot+ PC experiences, Intel® Core™ Ultra architecture, and interactive 360° hinge mode switcher (**Laptop**, **Tent**, **Stand**, and **Tablet** modes).
- **🛡️ Enterprise Security & Sustainability**: Dedicated sections for Dell SafeBIOS, Windows Hello biometrics, and 100% recycled packaging.
- **✨ Dell XPS 13 Ultra-Portable**: Interactive product card featuring InfinityEdge display specs, no-cost EMI details, hardware specs modal, and QR Code brochure modal.
- **🔌 Dell Accessories Hub**: Highlights the **Dell 6-in-1 Adapter DA305** and **Dell Pro 7-in-1 Travel Hub DA326** with 80% discount bundle redemption modals.
- **🎧 Special Offers & Bundles**: **JBL Tune 770NC** Adaptive Noise Cancelling Headphones promotional voucher reservation form.
- **📍 Floating Section Navigation**: Quick side-dot indicator for smooth one-click navigation across all 7 assignment sections.
- **📱 Fully Responsive**: Tailored for all screen sizes from mobile devices to 4K displays.

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/dell-assignment.git
cd dell-assignment
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
